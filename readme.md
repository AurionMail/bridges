# Aurion Bridges
These bridges are used to communicate between the different apps of the Aurion Suite
## Use it
- Replace WEBMAIL_ORIGIN, SSO_ORIGIN, SAND_ORIGIN, PAD_ORIGIN and SSO_ORIGIN by your values.
- Put them in `/var/www/aurion-bridges/` 
-  `sudo chown -R www-data:www-data /var/www/aurion-bridges/`
